Conectar ao GitHub

Para publicar o cardápio, este aparelho precisa de uma chave de acesso do GitHub (feito uma vez só por aparelho):

  1. Abra este link com a conta do GitHub dona do site.
  2. Em Repository access, escolha Only select repositories e selecione .
  3. Em Permissions › Repository permissions, deixe Contents como Read and write.
  4. Clique em Generate token, copie a chave e cole abaixo.
